Se elige un evento finalizado desde la API (con sus inscritos) y se carga la clave: pregunta, respuesta y puntaje.

2

Escaneo a imagen

Cada página del PDF escaneado se convierte en una imagen a 300 dpi; cada página es la hoja de un participante.

pdf2imagePoppler
3

Referencias y recorte

Umbral de Otsu y contornos: se buscan 6 cuadrados negros (4 vértices, forma cuadrada, más de 80% de relleno) y se recorta el área entre ellos.

OpenCVfindContours
4

Lectura de marcas

1 marca → respuesta
0 marcas → sin marcar
2+ marcas → inválida

En cada círculo se cuenta la proporción de píxeles oscuros: con 50% o más, está marcado. Así se leen las 30 respuestas y los 8 dígitos del DNI.

máscara circular≥ 50%
5

Nota y reporte

Se valida que el DNI esté inscrito, se suma el puntaje de cada acierto y se guarda la evaluación en la API con el PDF de evidencia.

ReportLabAPI Laravel
puntaje = Σ pts(p) si marca(p) = clave(p)
nota   = puntaje / Σ pts × 100
